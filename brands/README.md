# brands/

One folder per brand. The **active brand** is set by `brand:` in `INPUTS.md`.

```
brands/
  _example/        copy this to start a new brand (ships with the repo)
  <brand_id>/
    brand.yaml     exact tokens (palette, fonts, wordmark)
    GUIDELINES.md  voice + visual rules
    examples/      3–6 reference designs
```

To add a brand, see **`ONBOARDING.md`** (has a copy-paste prompt).
Real brand folders are gitignored (your content); only `_example/` ships.
